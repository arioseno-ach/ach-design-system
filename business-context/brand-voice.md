# Brand voice

Tone, words to use, and words to avoid. Complements `design.md`; this file is product-specific.

## Tone

Calm, clear, adult. Helpful without being familiar.

## Terminology

| Use | Do not use | Notes |
| --- | --- | --- |
| Continue | Next (unless stepper label) | Primary wizard action |
| Save changes | Update / Submit (unless form is a legal submission) | |
| Review | Check / Double-check | |
| Details | Info | |

## Do

- Address the user as “you”.
- Name the object: “Save address”, not “Save”.
- Explain errors with a next step.

## Don’t

- Exclamation marks in UI chrome.
- Emoji in system UI unless a component spec allows it.
- Blame the user (“You entered the wrong…” → “This number doesn’t match our records.”).
- Internal code names, ticket IDs, or stack traces in UI copy.
